What EdgeMeter does

One device. Three jobs. Done at the edge.

Each function is built into firmware on the device, designed against an operator outcome — losses found, settlement cleared, customer served — rather than a feature checklist.

Utility metering

Records electricity to ±0.5% accuracy in both directions. Detects tamper, manages load, responds to faults — all from the device. No round-trip required.

Real-time data

Every meter event leaves the device as structured data. Any modern system reads it directly: dashboards, billing, analytics, ML pipelines, spreadsheets. No middleware.

Payment terminal

Settles payments at the device. Works with the rails customers already use — bank transfer, mobile money, card. The meter knows when settlement clears.
